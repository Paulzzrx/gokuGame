# Goku Battle

**Goku Battle is a small 2D game developed in C# using Windows Forms (SharpDevelop).**
The project was created with the goal of practicing Object-Oriented Programming (OOP) concepts, such as encapsulation, inheritance, and polymorphism, all applied in a fun context — a battle between two characters controlled by the keyboard.

---

### 🎯 Project Goals

This project is part of a Object-Oriented Programming course activity, with the following purposes:
Practice using classes, objects, and methods in C#.
Work with events and timers in a Windows Forms interface.
Develop a simple game featuring movement, animations, and player interaction.

---

### 🕹️ How to Play
👤 Player 1 (Left Goku)
| Action | Key |
|------|--------|
| Move Up |	`W` |
| Move Down | `S` |
| Move Left |	`A` |
| Move Right |	`D` |
| Attack |	`Space` |

👤 Player 2 (Right Goku)
| Action | Key |
|------|--------|
| Move Up |	`I` |
| Move Down | `K` |
| Move Left |	`J` |
| Move Right |	`L` |
| Attack |	`Enter` |

Both characters can move freely and attack each other by launching projectiles.
Each attack changes the character’s animation and displays the projectile in the correct facing direction.

---

### 🧠 OOP Concepts Applied

The project will be expanded over time to apply the following concepts:
Classes and Objects – Representing players, attacks, and scene elements.
Encapsulation – Dividing responsibilities among classes (e.g., Hero, Enemy, Attack).
Inheritance – Creating subclasses for different character types.
Polymorphism – Allowing actions and attacks to behave differently depending on the character type.
